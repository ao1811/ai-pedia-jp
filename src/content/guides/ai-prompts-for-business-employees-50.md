「会社でAIを使えと言われたけど、何のプロンプトを書けばいいか分からない」——非エンジニアの会社員が最も詰まる場所です。本記事では **10部署×5プロンプト=50本** の実用プロンプト集を、コピペで使える形で公開します。

## 結論：10部署×5プロンプトの完全網羅

短く言うと、以下の10部署それぞれに **5本の実用プロンプト**：

1. 営業 → 顧客リサーチ・提案・議事録など
2. マーケ → 記事執筆・広告コピー・分析
3. 人事 → 採用・研修・社内通達
4. 経理 → 請求書・レポート・分析
5. PdM → 仕様書・競合調査・KPI
6. CS → 返信・FAQ・苦情対応
7. 経営企画 → 中計・分析・レポート
8. 法務 → 契約書・規程・リスク
9. IT・情シス → 仕様書・障害対応・移行
10. 広報・PR → プレス・SNS・原稿

すべて ChatGPT Plus / Claude Pro で動作検証済みです。

ツール選定は[AIツール選び方フローチャート](/guides/ai-tool-selection-for-business-employees/)、運用前提は[「会社でAIを使え」と言われた人の30日ロードマップ](/guides/ai-at-work-first-30-days-plan/)、セキュリティは[会社でAIを使う前のチェックリスト](/guides/corporate-ai-security-compliance-checklist/)を参照。

## 営業職（5本）

### 1. 顧客企業の事前リサーチ

```
以下の企業について、商談前のリサーチを行ってください。

対象企業：[企業名]（URL: [URL]）

調査項目（必ず全て含めてください）：
1. 事業概要（200字以内）
2. 直近6ヶ月のプレスリリース・ニュース TOP 10（要約付き）
3. 公開されている経営課題・成長戦略
4. 競合企業3社（推定理由つき）
5. 接点候補となるキーパーソン（部署・氏名のみ、公式情報のみ）

出力形式：Markdown 表 + 要約テキスト
```

### 2. 提案メール下書き

```
[相手の状況] のクライアントへの提案メール下書きを書いてください。

要件：
- ビジネスフォーマルなトーン
- 結論ファースト（要件 → 詳細 → 期限）
- 300〜500字
- 具体的な次回アクションを明記
- 「〜と存じます」「〜いただけますと幸いです」を適切に使用

提案内容：[具体的な内容]
返信期限：[日付]
```

### 3. 議事録の整形

```
以下の商談メモを整形してください：

[メモを貼り付け]

出力形式：
1. 商談概要（日時・参加者・テーマ）
2. 議論された主要トピック（最大5つ）
3. アクションアイテム（担当者・期限・優先度を表化）
4. 次回までの確認事項
5. 関連 Notion ページへのリンク
```

### 4. 競合製品の比較分析

```
以下の3社の製品を比較分析してください：

対象：
1. [自社製品名]
2. [競合A]
3. [競合B]

比較軸：
- 機能（5項目）
- 料金（プラン別）
- 強み・弱み
- 想定顧客層

出力：比較表 + 各社のサマリー（200字）+ 自社の差別化ポイント
```

### 5. クロージング時の Q&A 想定

```
[商談相手の業界・役職] が聞いてきそうな質問 TOP 10 を想定してください。

商品・サービス：[内容]
営業フェーズ：[初回 / 提案 / クロージング]

各質問について：
- 質問文
- 想定される懸念
- 回答テンプレ
- 補足資料の有無

を整理してください。
```

## マーケティング職（5本）

### 6. ブログ記事の構成案

```
[キーワード] でSEO上位を狙うブログ記事の構成案を作ってください。

ターゲット：[読者層]
文字数目標：5,000〜7,000字

含めるべき要素：
- タイトル案 5つ
- meta description（150字以内）
- H2 5つ + 各 H2 配下の H3
- 各セクションの想定文字数
- 関連キーワード（共起語）10個
- FAQ 5問

競合上位10サイトの構成を踏まえて、差別化ポイントも提案してください。
```

### 7. 広告コピーの A/B 案

```
[商品・サービス] の Google 広告（リスティング）コピーを A/B テスト用に5案作成してください。

商品：[詳細]
ターゲット：[読者層]
訴求軸：[コスパ / 機能 / 安心感 / 等]

各コピーは：
- 見出し 30字以内
- 説明文 90字以内
- 訴求ポイント

を含めてください。CTRが高そうな順にランク付けしてください。
```

### 8. SNS 投稿カレンダー

```
来月（1ヶ月分）の X / Twitter 投稿カレンダーを作成してください。

ブランド：[ブランド名]
投稿頻度：週3〜5本
トーン：[親しみやすい / プロフェッショナル / 等]

含めるべきテーマミックス：
- 業界トレンド（30%）
- 自社製品紹介（20%）
- お客様事例（20%）
- 中の人の発信（15%）
- 季節・イベント（15%）

各投稿：日付・テーマ・本文（140字以内）・ハッシュタグ
```

### 9. メルマガの件名 A/B

```
[内容] のメルマガ件名を A/B テスト用に10案作成してください。

メルマガ目的：[クリック誘発 / 開封率向上 / セール告知]
ターゲット：[読者層]

各件名：
- 25字以内
- 開封率の予測（High / Mid / Low）
- 訴求ポイント

を含めてください。
```

### 10. ペルソナ作成

```
[商品・サービス] のターゲットペルソナを3人作成してください。

各ペルソナ：
- 名前（仮）・年齢・性別・職業
- 年収・家族構成
- 利用シーン・課題
- 購入決定要因
- 普段利用するメディア
- 響く訴求ポイント

データに基づく現実的なペルソナにしてください。
```

## 人事・総務職（5本）

### 11. 採用候補者リサーチ

```
採用候補者の公開情報を整理してください。

候補者：[氏名（仮名）]
応募職種：[職種]
LinkedIn URL: [URL]

調査項目：
1. LinkedIn 公開プロフィール
2. GitHub 公開リポジトリ（エンジニアの場合）
3. X / 個人ブログ・Qiita / Zenn
4. カンファレンス登壇歴

出力：「事実」と「採用観点での解釈」を分けて記載
注意：差別につながる情報（学歴・年齢・宗教等）は記載しない
公開されている公式情報のみ
```

### 12. 社内通達の文章

```
[テーマ] の社内通達文を作成してください。

対象：全社員
トーン：丁寧 + 必要な権威性
含める要素：
- 件名
- 背景・目的
- 具体的な変更点
- 開始日・期限
- 問い合わせ先
- 補足資料へのリンク

500〜800字でまとめてください。
```

### 13. 研修プログラムの構成

```
[テーマ] の社内研修プログラムを作成してください。

対象：[新人 / 中堅 / 管理職]
研修時間：[2時間 / 半日 / 1日]

含めるべき：
- 学習目標（3つ以内）
- アジェンダ（時間配分つき）
- ワークショップ・演習
- 配布資料の項目
- 効果測定方法（アンケート設計）

ファシリテーターガイド形式で出力。
```

### 14. 社員向け FAQ 整備

```
以下のテーマで社員から問い合わせが多い質問 TOP 20 を想定して FAQ を作成してください：

テーマ：[就業規則 / 福利厚生 / 経費精算 / IT サポート]

各 Q&A：
- 質問文（社員が検索しそうな自然な日本語）
- 回答（200〜300字、箇条書きOK）
- 関連規程・連絡先

カテゴリ別に整理してください。
```

### 15. 1on1 のテンプレート

```
[役職] 向けの 1on1 ミーティングのテンプレートを作成してください。

時間：30分

- キャリアの展望
- マネジメントへのフィードバック

各項目に質問例を3つずつ含めてください。
```

## CS・カスタマーサポート（5本）

### 26. お客様返信の整形

```
カスタマーから受信した以下の問い合わせに対する返信を、以下の方針で書いてください：

問い合わせ内容：[コピー]

方針：
- 共感的な書き出し（謝意 or 同意）
- 解決策を具体的に（番号付き）
- 想定される追加質問への対応も含める
- 締めに「お困りの際は再度お問い合わせください」
- 200〜400字
```

### 27. FAQ の自動生成

```
過去90日の Zendesk チケット（解決済み）を読み込み、頻出する質問パターンを FAQ にしてください。

実行手順：
1. Zendesk の解決済みチケットを取得
2. 質問内容をクラスタリング
3. 上位20パターンをピックアップ
4. 各パターンを Q&A 形式で生成

出力：
- 質問文
- 回答（300〜500字）
- 元になったチケット数
- カテゴリ
```

### 28. 苦情対応の文面

```
以下の苦情への対応文を作成してください：

苦情内容：[詳細]

含めるべき要素：
1. 共感・謝罪
2. 状況の確認
3. 取った対応
4. 再発防止策
5. 補償（提案）
6. 継続的な改善コミット

トーン：誠実、責任感あり、感情的にならない
500〜800字
```

### 29. ナレッジベース記事

```
[トピック] のナレッジベース記事を作成してください。

ターゲット：[初心者 / 中級者]
文字数：1,500〜2,500字

構成：
1. 概要（150字）
2. ステップバイステップ手順（5〜7ステップ、スクショ付き）
3. よくある間違い
4. トラブルシューティング
5. 関連リンク

スクリーンショット箇所には [Screenshot: 詳細] と明記
```

```
四半期計画として整理。
```

## 経営企画（5本）

### 31. 業界トレンド分析

```
[業界] の2026年の重要トレンドを整理してください。

調査範囲：
- 経済産業省・関連業界団体の発表
- 主要企業の決算情報
- 業界レポート（民間）
```

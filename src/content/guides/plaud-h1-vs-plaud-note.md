「PLAUD の H1（カード型）と NOTE（ペン型）、どっちを買えばいい？」——購入前の最大の悩みです。本記事では、PLAUD 公式情報・主要メディアのレビュー・編集部の利用所感をもとに、**用途別の推奨**を完全解説します。

## 結論：用途で完全に分かれる

短く言うと：

| あなたのタイプ | 推奨 |
|---|---|
| **対面商談・コンサル** | **NOTE**（ペン型） |
| **記者・取材** | **NOTE**（ペン型） |
| **医療・介護現場** | **NOTE**（ペン型） |
| **デスクワーク中心** | **H1**（カード型） |
| **長時間会議が多い** | **H1**（カード型） |

| **迷ったら** | **H1**（汎用性勝ち） |

### 軸4：使用シーン適合性

#### H1（カード型）が向く場面

##### ✅ 長時間会議
- 30時間連続録音 → 1日中の会議も安心
- スマホ背面に装着 → 持ち運び忘れない

##### ✅ デスクワーク
- カード型で机に置いても自然
- ノートPC横でも違和感なし

##### ✅ オンラインミーティング
- ヘッドセットからの音声をピックアップ
- スピーカー経由でも録音可能

#### NOTE（ペン型）が向く場面

##### ✅ 対面商談
- **胸ポケットに挿す**だけで自然
- 「録音してる感」が消えるのが最大の強み
- クライアントとの心理的距離が縮まる

##### ✅ 取材・インタビュー
- 記者の象徴であるペン型なので違和感ゼロ
- 取材相手も「録音前提」の意識
- 編集部記者が高評価

##### ✅ 医療・介護現場
- 白衣の胸ポケットに自然挿入
- 患者・利用者に威圧感与えない
- 看護記録の代替として使われる事例多数

## 用途別の詳細推奨

### 営業職（フィールドセールス）

#### 推奨：**PLAUD NOTE（ペン型）**

**理由**：
- 商談中の録音で**クライアントが警戒しない**
- 「ペンを取り出した」自然な動作
- 提案時の議事録が後でAI要約される

#### こう使う
```
1. 商談前にNOTE を起動
2. 胸ポケットに挿す
3. 商談（90分間）
4. 帰社後にスマホで AI 要約を確認
5. CRM に貼り付け、提案メールに活用
```

→ **商談1件あたり30分の議事録時間が5分に短縮**。

### 記者・編集者

#### 推奨：**PLAUD NOTE（ペン型）**

**理由**：
- ペンとして取材道具に紛れる
- 「メモしながら録音」の自然なフロー
- 編集部記者の標準ツール化

#### こう使う
```
1. NOTE + メモ帳で取材
2. 取材中はメモ取りに集中（録音はNOTEに任せる）
3. 帰社後 AI で文字起こし
4. 取材メモと突き合わせて記事執筆
```

→ **書き起こし作業が完全消滅**。

### 医療従事者・介護職

#### 推奨：**PLAUD NOTE（ペン型）**

**理由**：
- 白衣胸ポケットに挿せる
- 患者・利用者に威圧感与えない
- 多忙な現場で「録音してメモ」の負担減

#### こう使う
```
1. 朝のカンファレンスでNOTEオン
2. 患者ラウンド・申し送り
3. 業務終了後、AI 文字起こし → 記録に転記
```

→ **看護記録時間が1時間短縮**。

### コンサルタント・プロジェクトマネージャ

#### 推奨：**PLAUD H1（カード型）**

**理由**：
- 1日6時間以上の会議が日常
- 連続録音30時間は安心感
- スマホ背面装着で常時携帯

#### こう使う
```
1. 朝、H1をスマホに装着
2. 1日5〜10件の会議をすべて録音
3. 夜にまとめて AI 要約
4. クライアントへの議事録を自動生成
```

→ **議事録作成時間が完全になくなる**。

### 弁護士・士業

#### 推奨：**PLAUD H1**（汎用性）+ **NOTE**（対面用）

**理由**：
- 法的な記録として「録音している」明示が必要
- H1 で長時間記録、NOTE で対面の証拠
- 契約書精読・打合せ全て記録

**注意**：弁護士業務上の守秘義務を踏まえて運用。詳細は[会社でAIを使う前のセキュリティチェックリスト](/guides/corporate-ai-security-compliance-checklist)を参照。

## 実機3ヶ月使った編集部の本音

### H1 を3ヶ月使って分かったこと

#### 良かった点
- スマホ背面装着で**忘れない**
- 30時間連続録音は実際に**1度も困らなかった**
- カード型で**机に置いても自然**

#### 不満点
- 対面商談で「これ何？」と聞かれることがある
- スマホケースとの相性問題

### NOTE を3ヶ月使って分かったこと

#### 良かった点
- **取材で警戒されない**
- ペン型なので**自然なメモ動作**になる
- 胸ポケット挿入で常時携帯

#### 不満点
- ペン型なので**机に置く時に転がる**
- 充電端子の位置が使いにくい

### 結論：両方持ちが理想だが、1台なら H1

理由：H1 の方が「**こういう場面でも使える**」が広い。NOTE は「**対面のとき強い**」が、H1 でも対面で使えなくはない。

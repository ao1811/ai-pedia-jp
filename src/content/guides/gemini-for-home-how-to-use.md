「Gemini for Home の設定は終わったけど、何に使えばいいかわからない」——この悩みを解決するために、**実用コマンド50パターン**を用途別にまとめました。Google 公式情報・編集部の検証・公開ベータユーザーの声をもとに、**毎日使える機能だけ**を厳選しています。

## 結論：Gemini for Home の3大強化ポイント

```
1. 多段階タスク：1コマンドで複数の動作を連鎖
2. 文脈理解：「もっと詳しく」「別の案は？」など追加質問OK
3. 創造的応答：物語・ジョーク・レシピを生成
```

これが従来の Google Assistant との最大の違い。**「1問1答ロボ」から「会話できる助手」へ**進化したと考えてください。

## 基本コマンド10選（毎日使う）

### 1. 朝のルーティン

## 認識精度を上げる5つのコツ

### 1. **シンプルな日本語**
「えーと、あの、リビングの…」より「リビングの電気消して」

### 2. **語尾を明確に**
「電気つけて」「電気消して」など、動詞をはっきり

### 3. **固有名詞は省略**
「〇〇さんから来た」より「最新メール」

### 4. **時刻は具体的**
「あとで」より「30分後」「夕方6時」

### 5. **Voice Match の再登録**
1〜2ヶ月に1回、声の変化を反映するため再登録

## やってはいけないこと

### NG1：機密情報を音声で扱う
```
NG: 「OK Google、銀行のパスワードを教えて」
```
→ 音声データはクラウド処理されるため、機密はテキスト or 専用アプリで

### NG2：常時会話モード
```
NG: 「OK Google、ずっと聞いてて」
```
→ プライバシー観点で家族の同意必須。Gemini Live は意図して使う

### NG3：無料プラン外の機能を期待
Gemini Live、長時間連続会話、カスタムルーティン高度機能などは Google Home Premium が必要

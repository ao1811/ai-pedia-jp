「Nest Hub と Echo Show 5、どちらを買えばいい？」——スマートスピーカー選びの最大の悩みです。本記事では、Google・Amazon の公式情報、主要メディアのレビュー、編集部の利用所感をもとに、**4軸で徹底比較**します。

## 結論：エコシステムで選ぶ

短く言うと：

| あなたのタイプ | おすすめ |
|---|---|
| **Google Workspace 利用者** | **Nest Hub** 一択 |
| **Amazon Prime 会員** | **Echo Show 5** |
| **iPhone がメイン** | △ 両方、HomePod を待つ手も |
| **AI 性能重視** | **Nest Hub**（Gemini for Home 強い） |
| **ショッピング多用** | **Echo Show 5**（Alexa+ 強い） |
| **子供の教育用** | **Nest Hub**（Family Link 強い） |

設定方法は[Nest Hub × Gemini の設定方法](/guides/nest-hub-gemini-setup)、Gemini for Home 全体像は[Gemini for Home の使い方完全ガイド](/guides/gemini-for-home-japan-2026)を参照。

## 4軸の徹底比較

### 軸1：価格・性能

| 項目 | Nest Hub | Echo Show 5 |
|---|---|---|
| 価格 | ¥15,000 | ¥9,980 |
| 画面サイズ | 7インチ | 5.5インチ |
| 解像度 | 1024×600 | 960×480 |
| スピーカー | フルレンジ × 1 | スピーカー × 1 |
| マイク | 3マイク | 2マイク |
| カメラ | なし（Hub Max は有） | 2MP（プライバシーシャッター付き） |

**コスパ**：Echo Show 5 圧勝（¥5,000差）
**性能**：Nest Hub の方が画面・スピーカー上

### 軸2：AI 性能

| 項目 | Gemini for Home（Nest Hub） | Alexa+（Echo Show 5） |
|---|---|---|
| 会話の自然さ | ⭐⭐⭐ | ⭐⭐ |
| 複雑な質問理解 | ⭐⭐⭐ | ⭐⭐ |
| 文脈保持 | ⭐⭐⭐ | ⭐⭐ |
| 多言語対応 | ⭐⭐⭐ | ⭐⭐ |
| ショッピング統合 | ⭐ | ⭐⭐⭐ |
| 買い物リスト | ⭐⭐ | ⭐⭐⭐ |
| 配送追跡 | △ | ⭐⭐⭐ |
| Audible 連携 | × | ⭐⭐⭐ |

**AI 会話品質**：Gemini for Home が一段上
**ショッピング**：Alexa+ が圧勝

### 軸3：エコシステム連携

#### Nest Hub の強み
- **Google Workspace**：Gmail / カレンダー / Drive / Photos 完全統合
- **YouTube / YouTube Music**：ネイティブ対応
- **Google Photos**：スライドショー機能（料理中の写真表示等）
- **Pixel ファミリー**：Pixel スマホとの連携

#### Echo Show 5 の強み
- **Amazon Prime**：Prime Video、Prime Music
- **Audible**：オーディオブック
- **ショッピング**：Echo から直接購入
- **Ring**：玄関カメラ連携（Amazon傘下）

### 軸4：ファミリー機能

#### Nest Hub × Family Link
- **13歳未満の子供アカウント**を細かく管理
- **コンテンツフィルタ**：暴力・成人向けブロック
- **使用時間制限**：曜日・時間帯指定
- **学習進捗**：Google Classroom 連携
- **Google Photos 共有**：家族で写真ライブラリ

#### Echo Show 5 × Echo Dot Kids
- **キッズスキル**：年齢に応じたコンテンツ
- **時間制限**：シンプルな設定のみ
- **子供向けゲーム**：Alexa スキルから多数
- **音楽**：Amazon Music Kids

**子供向け**：Nest Hub の方が**学習面で深い**

## ユースケース別の推奨

### ユースケース1：朝のルーティン

#### Nest Hub
```
「Hey Google、おはよう」
→ 天気 + カレンダー + Gmail要約 + 通勤情報
```

Google エコシステムなら情報が**全部統合**。

#### Echo Show 5
```
「Alexa、おはよう」
→ 天気 + ニュース + 音楽
```

シンプル、でもカレンダー連携は Google より弱い。

→ **Workspace 派は Nest Hub 圧勝**

### ユースケース2：料理中

#### Nest Hub
- **クックパッド連携**で人気レシピ
- **Google Photos** で過去の料理写真スライドショー
- **タイマー複数同時**

#### Echo Show 5
- **DELISH KITCHEN** 動画レシピ
- **Amazon Fresh** で食材即発注
- **タイマー複数同時**

→ **どちらも優秀、好み次第**

### ユースケース3：ショッピング

#### Echo Show 5
```
「Alexa、トイレットペーパーを買い物リストに追加」
→ Amazon の購入履歴から最適商品を提案
→ ワンタップで注文確定
```

**Amazon との統合が圧倒的**

#### Nest Hub
```
「Hey Google、買い物リストにトイレットペーパー追加」
→ Google Keep に追加
→ 自分で買い物に行く
```

ショッピング機能は弱い。

→ **Prime会員は Echo Show 5 一択**

### ユースケース4：子供の宿題サポート

#### Nest Hub × Gemini
```
子供：「九九の7の段教えて」
→ Gemini：年齢に応じた丁寧な説明
→ 「もう少し練習する？」と続く対話
```

**Gemini の対話品質が圧倒的**

#### Echo Show 5
```
子供：「九九の7の段教えて」
→ Alexa：機械的に列挙
```

子供向けスキルもあるが、対話品質で差。

→ **教育用途は Nest Hub**

## 編集部の最終推奨

### 「迷ったら Nest Hub」

理由：
1. **Gemini for Home の会話品質**が Alexa+ より上
2. **Google Workspace ユーザー多数**（個人・法人とも）
3. **AI の進化速度**（Gemini の方が更新頻度高い）
4. **画面サイズ7インチ**で視認性良い

### 「Prime会員は Echo Show 5」

理由：
1. ショッピング統合が圧倒的
2. ¥9,980 と安価
3. Audible / Prime Video / Prime Music が充実

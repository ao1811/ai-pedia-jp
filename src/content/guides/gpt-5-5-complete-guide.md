## 新機能ハイライト

### 1. エージェント型コーディングの精度UP

GPT-5.5 は **「指示してから完成までの工程をエージェントが自律的に進める」**精度が大幅向上しました。

```
GPT-5.4：「ファイル作成 → コード書く → テスト書く → 修正」
        各ステップで人間の確認が必要、ミスも多い

GPT-5.5：上記の工程を一気通貫で完了
        テスト失敗時は自動で修正、最後に成果物だけ確認
```

具体例：

```
ユーザー：「Astro で記事一覧ページを作って、SEO 最適化して」

GPT-5.4：プロンプトを4-5回に分けて指示が必要
GPT-5.5：1プロンプトで完成（テスト含む）
```

### 2. PC 操作（Computer Use）の理解力UP

```
ユーザー：「このスプレッドシートの今月の経費を、Slack の #経費 チャンネルに投稿して」

GPT-5.5：
1. スプレッドシートを開く
2. 今月分のデータを抽出
3. 集計
4. Slack を開く
5. #経費 チャンネルに投稿
6. 完了報告
```

各ステップでの誤操作・誤解釈が GPT-5.4 比で大幅減少。**「Claude の Computer Use と並ぶレベル」**まで来たのが GPT-5.5 の最大の進化です。

### 3. 長文一貫性

10,000字以上のレポート作成で **論理破綻・自己矛盾**が起きにくくなりました。

```
GPT-5.4：8,000字を超えると前後の整合性が崩れることがあった
GPT-5.5：15,000字まで一貫性を保てる（編集部検証）
```

ライター・研究者・コンサルタントには重要な改善です。

### 4. 日本語自然性

編集部の体感では：

```
GPT-5.4 まで：時々「翻訳調」が混じる
GPT-5.5：ネイティブ日本人が書いた文章に近づいた
```

特に **敬語・ビジネス文書・口語**のバランスが改善しています。

### 5. 推論安定性

複雑な質問への応答時間のブレが少なくなりました。

```
GPT-5.4：ピーク時に応答時間が3〜10倍に伸びることがあった
GPT-5.5：ブレが大幅縮小、平均レイテンシも短縮
```

## 知っておくべき注意点

### 1. 旧モデル（GPT-5）も並行提供中

GPT-5.5 リリース後も GPT-5 / GPT-5.4 は ChatGPT 内で選択可能です。**Free プラン**は GPT-5 のみ、コードや複雑な質問は劣化を感じる可能性があります。

### 2. Sora 終了の影響（2026-04-26）

OpenAI は Sora（動画生成）を 4月26日にアプリ終了、API も9月24日終了予定。Pro プラン（¥30,000/月）の主な訴求機能だった Sora がなくなり、**Pro 加入者は実質的にダウングレード**を検討すべき時期です。代替は[Sora 終了→代替AI動画生成5選](/guides/sora-shutdown-alternatives/)で解説。

### 3. ChatGPT 16,800円 Codex プランの新設

エンジニア向けに **¥16,800/月の Codex プラン**が4月9日に新設されました。GPT-5.5 + コーディング特化機能で、Pro プランより安価。詳しくは[ChatGPT Codex プラン完全解説](/guides/chatgpt-codex-plan-16800/)を参照。

### 4. プロンプトの最適化が必要

GPT-5.5 の能力を引き出すには、**従来より詳細なプロンプト**が有効です。

```
GPT-5.4 までのスタイル：「メールの返信をください」
GPT-5.5 推奨スタイル：「以下のメールに、相手のトーンに合わせて、3つの提案を含めて返信。文末は丁寧、200字以内」
```

### 5. エージェント機能は最適化のため徐々にロールアウト

GPT-5.5 のエージェント機能は **段階的に有効化**されているため、初日に全機能が使えない可能性があります。1〜2週間で全ユーザーに展開予定。

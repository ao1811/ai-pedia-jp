「コーディングAI ツールに何を契約すべき？」「Cursor / Claude Code / Copilot 全部？」——導入前の最大の疑問はこれです。本記事では、各社公式情報・主要メディアのレビュー・編集部の利用所感をもとに、料金プラン・利用枠・ROI を完全比較します。

## 結論：エンジニアの月給に応じた料金最適解

短く言うと：

- **個人開発・学習** → **GitHub Copilot Free + Claude Free（併用）**
- **コード補完中心** → **GitHub Copilot Pro（$10/月）**
- **対話型編集 IDE** → **Cursor Pro（$20/月）**
- **CLI 派・軽量派** → **Claude Pro（$20/月）+ Claude Code**
- **両刀（Cursor + Claude Code）** → **月$40 で最強環境**
- **自律的コーディング** → **Devin（$500/月、要相談）**

ツール3本の機能比較は[コーディングAI比較（Cursor / Copilot / Claude Code）](/guides/coding-ai-comparison/)、Cursor 特化は[Cursor 完全実践ガイド](/guides/cursor-practical-guide/)、Claude Code 特化は[Claude Code 完全実践ガイド](/guides/claude-code-practical-guide/)で解説しています。

|---|---|---|---|---|

## GitHub Copilot：基礎中の基礎

### Copilot のプラン詳細

| プラン | 月額 | 主な機能 |
|---|---|---|
| Free（個人プロジェクト） | $0 | コード補完無制限（個人プロジェクトのみ） |
| Pro | $10 | 全機能、商用OK |
| Business | $19/人 | 管理機能、セキュリティ |
| Enterprise | $39/人 | 高度なセキュリティ、SAML |

### Copilot が強い場面

- **コード補完**：行単位、関数単位の補完精度が依然最強
- **GitHub 統合**：PR・Issue 連携が滑らか
- **VS Code 拡張**：1クリックでセットアップ
- **言語サポート**：Python / TypeScript / Go / Rust / Java など全方位

### Copilot の弱点

- **対話的な大規模変更**は苦手（行補完中心）
- **リファクタリング**の精度は Cursor / Claude Code に劣る
- **多ファイルにまたがる変更**は手作業

## Cursor：フル IDE 体験

### Cursor の料金

| プラン | 月額（年払） | 月額（月払） | 主な機能 |
|---|---|---|---|
| Free | $0 | $0 | 月50クエリ |
| Pro | $16 | $20 | Claude / GPT-5 / Gemini Pro 月500クエリ |
| Business | $32 | $40 | チーム機能 + プライバシー強化 |
| Enterprise | $48 | $60 | SAML + SOC2 + 専任サポート |

### Cursor の強み

- **VS Code ベース**で慣れた UI
- **対話型編集**：「この関数をリファクタして」が一発で動く
- **マルチファイル理解**：プロジェクト全体の文脈で動作
- **Composer 機能**：複数ファイル同時編集
- **Agent モード**：タスクを自律的に進行

### Cursor が向く人

- **GUI 派エンジニア**で IDE で全部やりたい
- **VS Code に慣れている**
- **対話で大規模コード変更**したい
- **チーム開発**で同じ環境を統一したい

詳しい使い方は[Cursor 完全実践ガイド](/guides/cursor-practical-guide/)、Composer は[Cursor Composer / Agent Mode 解説](/guides/cursor-composer-agent/)を参照。

## Claude Code：CLI 派の最強

### Claude Code の料金

Claude Code は **Claude Pro / Max / Team / Enterprise の利用枠**を消費する形態：

| プラン | 月額 | Claude Code 利用枠 |
|---|---|---|
| Free | $0 | 限定的（試用程度） |
| Pro | $20 | 月数百回程度 |
| Max 5x | $100 | 月千回〜 |
| Team | $25/人 | Pro 同等 + 共有 |
| Enterprise | カスタム | 制限なし |

### Claude Code が強い場面

- **CLI からの呼び出し**：既存ターミナルワークフロー維持
- **Anthropic の安全性**：意図しないファイル削除が起きにくい
- **大規模リポジトリ**の文脈保持力
- **複雑なリファクタリング**の精度
- **テスト駆動開発**との相性

### Claude Code の弱点

- **GUI なし**：CLI 慣れていない人には敷居高い
- **VS Code 拡張は別途**（Continue.dev など）
- **コード補完単体**は Copilot に劣る

詳しい使い方は[Claude Code 完全実践ガイド](/guides/claude-code-practical-guide/)を参照。

## v0（Vercel）：UI/UX 特化

### v0 の料金

| プラン | 月額 | 主な機能 |
|---|---|---|
| Free | $0 | 月10生成 |
| Premium | $20 | 月100生成 |
| Team | $30/人 | チーム共有 |

### v0 が強い場面

- **Next.js + shadcn/ui** の UI 生成に最適化
- **Vercel デプロイ**との統合
- **生成 → そのまま動く**スピード

### v0 の弱点

- **Next.js 以外のフレームワーク**には限定的
- **Backend ロジック**は別途実装必要
- 一般的なコード編集は Cursor / Claude Code 推奨

[Claude Design](/guides/claude-design-feature/) との比較は別記事で詳述しています。

## Devin：自律的コーディング

### Devin の料金

| プラン | 月額 | 対象 |
|---|---|---|
| Team | $500/月 | スタートアップ・中小企業 |
| Enterprise | カスタム（月数十万〜） | 大企業 |

個人プランはありません。

### Devin の独自機能

- **Issue から自律的に PR を作成**：人間の介在最小限
- **テスト駆動の修正**：失敗するテストから自動修正
- **24時間動作**：夜間・週末も動く
- **GitHub 統合**：PR レビューに人間が入る形

### Devin の現実

月$500（約¥75,000）は **「エンジニア1人雇うより安い**」という判断ができる規模感の組織向け。個人開発者には高すぎ、しかし ROI が出るスタートアップには検討価値あり。

## 1年運用での総コスト・ROI試算

### ケース①：個人開発者（趣味・副業）

| 構成 | 月額 | 年額 | コード時間/月 | 時給ROI |
|---|---|---|---|---|
| GitHub Copilot Pro | $10（¥1,500） | ¥18,000 | 月20時間 | ¥75/時 = **67倍** |
| Cursor Pro | $20（¥3,000） | ¥36,000 | 月20時間 | ¥150/時 = **33倍** |
| Claude Pro + Claude Code | $20（¥3,000） | ¥36,000 | 月20時間 | ¥150/時 = **33倍** |
| 全部併用 | $40（¥6,000） | ¥72,000 | 月20時間 | ¥300/時 = **17倍** |

エンジニア時給¥5,000換算。**Copilot Pro 単独が個人にはコスパ最強**。

### ケース②：プロエンジニア（本業）

| 構成 | 月額 | 年額 | コード時間/月 | 削減効果 |
|---|---|---|---|---|
| Cursor Pro + Copilot Pro | $30（¥4,500） | ¥54,000 | 月160時間 | 月¥80,000相当 = **18倍** |
| Cursor Business + Copilot Business | $59 | ¥106,200 | 月160時間 | 月¥80,000相当 = **9倍** |
| Cursor Pro + Claude Code（Pro併用） | $40（¥6,000） | ¥72,000 | 月160時間 | 月¥120,000相当 = **20倍** |

本業ならツール代を惜しまず**最強環境**を組んだ方が ROI 高い。

### ケース③：スタートアップ（5人）

| 構成 | 月額（5人） | 年額 | エンジニア5人の生産性 |
|---|---|---|---|
| Cursor Business 5人 | $200（¥30,000） | ¥360,000 | 月¥400,000相当の節約 |
| Devin Team 1ライセンス | $500（¥75,000） | ¥900,000 | エンジニア1人分の自動化 |
| Cursor + Devin 併用 | $700（¥105,000） | ¥1,260,000 | 5人 × 1.5倍の効率 |

スタートアップなら **Cursor Business + Devin の併用**で「エンジニア6人分の生産性」を5人で達成可能。

## 「結局どれを選ぶべきか」意思決定フロー

```
START
  │
  ├── 自分はエンジニア？
  │   ├── No  → Claude Pro / ChatGPT Plus（コード補助で十分）
  │   └── Yes
  │       │
  │       ├── 主な作業は？
  │       │   ├── コード補完中心     → GitHub Copilot Pro
  │       │   ├── 対話的編集（GUI） → Cursor Pro
  │       │   ├── 対話的編集（CLI） → Claude Pro + Claude Code
  │       │   ├── UI 構築（Next.js） → v0 Premium
  │       │   └── 大規模自律実装    → Devin（要予算）
  │       │
  │       ├── 月のコード時間は？
  │       │   ├── 〜20時間   → Copilot Pro 単独で十分
  │       │   ├── 20〜80時間 → Cursor or Claude Code
  │       │   └── 80時間〜   → 両方併用 or Cursor Business
  │       │
  │       └── チーム or 個人？
  │           ├── 個人      → Pro プラン
  │           ├── 小チーム  → Team / Business プラン
  │           └── 大企業    → Enterprise（要相談）
END
```

## 編集部の運用：3ツール併用パターン

編集部おすすめの組み合わせ：

- **常用：Claude Pro + Claude Code（$20/月）** — サイト全体のコード変更
- **VS Code 拡張：GitHub Copilot Pro（$10/月）** — 行補完
- **必要時：Cursor Pro 単月（$20/月）** — 大規模リファクタリングが必要な月

合計 月$30〜$50（¥4,500〜¥7,500）で**プロエンジニア環境**を構築。Devin は予算的に手を出していません。

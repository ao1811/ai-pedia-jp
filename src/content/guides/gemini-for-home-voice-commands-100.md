「Gemini for Home を買ったけど、何を喋ればいいのか分からない」——日本のNestユーザーから最も多い悩みです。本記事では、Google 公式情報、主要メディアの解説、編集部の利用所感をもとに、シーン別に **100コマンド** を整理しました。

## 結論：Gemini for Home は「曖昧な日本語」で動く

短く言うと、Gemini for Home は **Alexa時代のような定型コマンドを覚える必要がない** AIです。

```
Alexa時代：「アレクサ、電気つけて」「アレクサ、タイマー10分」
Gemini時代：「そろそろ寝るからリビングだけ薄暗くして、明日の予定教えて」
```

**コツは3つ**：

1. **連続依頼OK**：「〇〇して、ついでに△△も」で複数タスクを一度に
2. **曖昧依頼OK**：「そろそろ寝る感じで」「いつもの感じ」で雰囲気で動く
3. **会話の続きOK**：「さっきの話の続き」「もうちょっと詳しく」で文脈保持

それでは、シーン別に100コマンドを見ていきましょう。

## シーン1：朝のルーティン（15コマンド）

朝のバタバタを Gemini に任せると、家を出るまでが10分は短縮できます。

```
1. ねぇGoogle、おはよう
   → 天気・気温・通勤情報・今日の予定を一括ブリーフィング

2. 今日の天気は？傘いる？
   → 1日の降水確率と気温推移、傘の必要性を判定

3. 通勤に何分かかる？
   → リアルタイム交通状況反映、遅延も警告

4. 今日の予定教えて
   → Googleカレンダーから読み上げ、優先度高は強調

5. ニュース3つ短く
   → 今朝の主要ニュースを30秒で要約

6. 朝のルーティン開始して
   → カーテン開ける + 電気つける + ニュース読む + 朝食タイマーを一括

7. 朝食のレシピ何かある？冷蔵庫の卵と食パンで
   → 簡単レシピを2〜3提案、調理時間付き

8. ゆで卵7分でタイマー
   → タイマー開始、終了時に「ゆで卵できたよ」と通知

9. 6時45分に出る予定なんだけど、何分前に準備すればいい？
   → 通勤時間逆算、起床時刻と支度開始時刻を提案

10. Spotifyで朝の元気が出る曲流して
    → ジャンル不問でテンション上げプレイリスト

11. コーヒーメーカーつけて
    → スマートプラグ経由でON

12. 子どもの登校時間まで何分？
    → 7:30なら「あと35分です。今は7時55分です（※朝寒いから上着を）」

13. 今日の花粉量は？
    → スギ・ヒノキ・イネの飛散レベル

14. 行ってきます、ルーティン実行
    → 全部屋電気OFF + エアコンOFF + 窓施錠確認 + 防犯モード

15. 妻に「もうすぐ家出る」って送って
    → Google Messages 経由でショートメッセージ送信
```

**ポイント**：1〜6を「朝のルーティン」として保存しておくと、「ねぇGoogle、おはよう」一発で全部実行できます。

    → Googleカレンダー作成

    → Gmail のスター付き未読を音声読み上げ

25. このメール、丁寧な返信を下書きして
    → Smart Reply に基づくドラフト生成

26. 在席中のステータスをSlackで「集中中」に変更
    → Slack 連携でステータス変更

27. 30分後に水分補給リマインドお願い

    → 連絡帳から検索

    → 事前作成のチェックリストを画面表示

31. 今、一番頭使う時間帯だから、家事はやらないで
    → スマート家電の自動運転を一時停止

    → 夕食関連ルーティンの時間調整

## 上達のコツ：「ルーティン」を作って一発実行

100個全部覚える必要はありません。Google Home アプリの **ルーティン機能** で、よく使う組み合わせをショートカット化しましょう。

### おすすめのルーティン化候補

| ショートカット名 | 含めるコマンド |
|---|---|
| **おはよう** | 朝の天気・予定・ニュース・カーテン・電気 |
| **行ってきます** | 全電気OFF・防犯ON・「行ってらっしゃい」声かけ |
| **集中モード** | 通知ミュート・タイマー・集中BGM |
| **おかえり** | 玄関ライト・空調・「お疲れさま」+ メッセージ確認 |
| **おやすみ** | 全電気OFF・施錠・空調・アラーム・読書ライト |
| **週末リラックス** | 暖色ライト・好きなBGM・写真スライドショー |

### 設定方法（5分）

```
1. Google Home アプリを開く
2. 右下「設定」→「ルーティン」
3. 「カスタムルーティン」→「+」
4. ショートカット名を設定（例：「おはよう」）
5. 含めるアクションを順番に追加
6. 起動方法（音声 / 時刻）を選択
7. 保存
```

これで「ねぇGoogle、おはよう」一発で5〜10コマンドが順次実行されます。

## よくある誤認識と回避法

### 1. 固有名詞（店名・人名）

**ダメな例**：「鳥貴族で予約して」（チェーン名は通る）vs 「とりよしで予約」（マイナーな店は通らない）

**回避**：「池袋の居酒屋『とりよし』で19時に2名予約」のように、地域 + カテゴリで絞ってから固有名詞を出す。

### 2. 方言・早口

**ダメな例**：「ちゃちゃっとアレやっといて」

**回避**：「リビングの電気を消して」のように動詞 + 目的語で明確に。

### 3. 指示語だけ

**ダメな例**：「アレ取って」「ソレやって」

**回避**：「さっきメモしたタスク、もう一度読んで」のように対象を補足。

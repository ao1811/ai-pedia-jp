## Sora 終了の経緯と影響

### 公式タイムライン

| 日付 | 出来事 |
|---|---|
| 2026-03-24 | OpenAI が Sora アプリ・API 終了を予告 |
| 2026-04-26 | Sora アプリ（ChatGPT 内）終了 |
| 2026-09-24 | Sora API 終了 |

### 出典

- OpenAI Help Center：[What to know about the Sora discontinuation](https://help.openai.com/en/articles/20001152-what-to-know-about-the-sora-discontinuation)
- The Decoder：[OpenAI sets two-stage Sora shutdown](https://the-decoder.com/openai-sets-two-stage-sora-shutdown-with-app-closing-april-2026-and-api-following-in-september/)

### 終了理由（OpenAI 発表）

```
「計算リソースを ChatGPT Enterprise・コーディング系
（GPT-5.5、Codex プラン）に集中させるため」
```

実際、OpenAI は同時期に：
- GPT-5.5 リリース（4月23日）
- 新 Codex プラン ¥16,800（4月9日）
- Disney との$150M 動画生成案件キャンセル（同時期報道）

を進めており、**動画生成事業からの戦略的撤退**と評価されています。

### Sora ユーザーへの影響

```
✅ 既存生成動画：ダウンロード可（個別保存推奨）
❌ 新規生成：4月26日以降不可
❌ API 利用：9月24日以降不可
❌ ChatGPT Pro の主な訴求機能を喪失
```

## よくある質問

### Q. ChatGPT Pro プランは解約すべき？

**A.** Sora が主目的だった人は **解約検討推奨**。

```
旧 Pro 価値：Sora 無制限 + Deep Research 無制限 + その他
新 Pro 価値：Deep Research 無制限 + その他（Sora なし）
```

代替案：

```
✅ Plus（¥3,000）+ Veo 3.1（無料）= ¥3,000/月
   → Sora 移行を完全カバー、¥27,000/月節約

✅ Codex（¥16,800）+ Veo 3.1（無料）
   → エンジニア向け、Pro より安く Sora 不要なら最適
```

### Q. Sora で作った動画は今後使える？

**A.** ダウンロード済みの動画は無期限に使えます。**4月26日までに必ずダウンロード**してください。

### Q. Veo 3.1 と Sora の品質差は？

**A.** 編集部の検証では **ほぼ同等**。

```
Veo の強み：音声統合、Google エコシステム連携、無料
Sora の強み：プロンプト解釈の細やかさ（ただし差は小さい）
```

### Q. Runway は高すぎませんか？

**A.** プロ案件のみ。個人利用なら Veo 3.1（無料）+ Pika（¥1,500）で十分です。

### Q. オープンソース系（Wan / LTX）はどれくらい使える？

**A.** **技術知識がある人専用**。一般ユーザーには Veo 3.1 を推奨します。

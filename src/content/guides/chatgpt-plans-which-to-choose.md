ChatGPT には Free・Plus（¥3,000/月）・**Codex（¥16,800/月・新設）**・Pro（¥30,000/月）の4プランがあり、**2026年4月の [GPT-5.5 リリース](/guides/gpt-5-5-complete-guide)**と **[Sora 終了（4/26）](/guides/sora-shutdown-alternatives)** で各プランの価値が大きく変わりました。本記事では編集部が全プランを使い分けた結果から、あなたに最適なプランを解説します。

## 結論：用途別に4プランを使い分ける時代

- **一般ユーザー** → **Plus**（¥3,000/月）一択、GPT-5.5 が使える
- **Freeでもいい人** → 週1〜2回しか使わない、GPT-5 軽量版で十分
- **エンジニア** → **[Codex](/guides/chatgpt-codex-plan-16800)**（¥16,800/月・新設）が最適解、Pro より安く Plus より高機能
- **Proを検討してた人** → Sora 終了で価値低下、Codex に移行が現実的

## 1. Free プランの実力

2026年の Free プランは、2022年のリリース時と比べ**格段に使える**ようになりました。GPT-5（軽量版）にもアクセスでき、日常的な質問・翻訳・簡単な要約なら十分です。

**Free で足りる用途**：
- 雑談、アイデア出し
- 短文の翻訳・要約
- 英語学習
- 簡単なコード質問

**Free で不足する用途**：
- 長文資料の処理（GPT-4o レガシーに制限）
- 画像生成の大量利用
- 最新モデル（GPT-5 Pro）の継続利用

## 2. Plus プランが選ばれる理由

月額 ¥3,000 で**価格対効果が最も高い**のが Plus。以下のいずれかに該当すれば確実に元が取れます。

- 1日3回以上 ChatGPT を開く
- 業務で資料作成やメール文案に使う
- 画像生成を週数回以上使う
- Deep Research を月10回以上使う

編集部の体感では、**Plus に1ヶ月使えば Free には戻れません**。生産性の差が月給以上の価値を生みます。

## 3. Codex プラン（¥16,800・新設）：エンジニアの新しい正解

2026年4月9日に新設された **エンジニア向けコーディング特化プラン**。Pro より44%安く、Plus より圧倒的に高機能。

### Codex プランが最適な人

- **コーディング業務がメイン** — GPT-5.5 がほぼ無制限
- **Cursor / Claude Code に課金している** — 乗り換え or 併用で AI コーディング強化
- **Plus でコーディングに限界を感じる** — 制限なしの快適さ
- **Pro 加入者で Sora を使わない** — Codex 移行で月¥13,200節約

### Codex で開放される機能

- GPT-5.5 ほぼ無制限利用
- Codex CLI（公式コマンドラインツール）
- VS Code / JetBrains / Cursor の IDE 拡張
- Codex Cloud（Computer Use エージェント）
- 優先応答・低レイテンシ

詳しくは[ChatGPT Codex プラン 16,800円 完全解説](/guides/chatgpt-codex-plan-16800)を参照。

## 4. Pro プランは誰のためか（Sora 終了で価値低下）

月額 ¥30,000 は個人には高額。さらに **2026年4月26日の Sora 終了で主要訴求機能が消失** したため、現状の価値は限定的です。

### Pro が真価を発揮する用途（限定的）

- **API 開発者** — $100分のクレジットが付く（実質値引き）
- **Research 業務** — Deep Research 無制限が必須
- **業務ヘビー利用** — 優先アクセスでピーク時も高速

### Pro に向かない人

- ~~Sora で動画生成を毎日使う~~ → 4/26 で Sora 終了、[Veo 3.1 無料化](/guides/veo-3-1-free-guide)で代替可能
- たまにしか使わない → Plus で十分
- コーディングメイン → Codex（¥16,800）が圧倒的にコスパ良い
- チーム利用 → Team プラン（¥3,750/月/ユーザー）の方がコスパ良い

### ライター・マーケター
→ **Plus**。Deep Research と画像生成で十分元が取れる

### エンジニア
→ **[Codex](/guides/chatgpt-codex-plan-16800)**（¥16,800）が最適。コーディング無制限。[Claude Pro](/guides/claude-opus-4-7-explained) と併用なら合計¥19,800で AI 開発最強体制

## プラン変更の注意点

- **月次課金なので、解約はいつでも可能**（次回請求日まで有効）
- 年額一括払いは2ヶ月分お得だが、解約時の返金なし
- Free → Plus は即時反映、Plus → Free はダウングレード予約制

## まとめ

- まず **Free** で試す（2週間）
- 日常ツールにするなら **Plus**（¥3,000・GPT-5.5 利用可）
- エンジニア・コーディングメインなら **Codex**（¥16,800・新設）
- 動画は [Veo 3.1 無料](/guides/veo-3-1-free-guide) で代替、Sora は4月26日終了
- Deep Research 無制限が必須なら **Pro**（¥30,000）
- 法人は **Team** を優先検討

料金だけでなく「使用頻度 × 生産性の上昇」で判断すると、最適なプランが見えてきます。

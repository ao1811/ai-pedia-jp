```
Step 1（5分）：設定で有効化・ダウンロード
Step 2（10分）：Writing Tools で文章リライト
Step 3（15分）：Siri 強化機能を試す
```

## Step 1：有効化（5分）

### 対応端末の確認

#### iPhone
```
✅ iPhone 15 Pro / 15 Pro Max
✅ iPhone 16 全機種
❌ iPhone 15（標準）以前
```

#### iPad / Mac
```
✅ M1 以降のすべて
❌ Intel Mac
❌ A シリーズ iPad
```

### 有効化手順

#### iPhone / iPad

```
1. 設定 を開く
2. 「Apple Intelligence & Siri」をタップ
3. 「Apple Intelligence」を ON
4. ダウンロード開始（5〜10分・約3GB）
5. 完了通知が来たら利用開始
```

**注意**：ダウンロード中は **Wi-Fi 環境** + **充電器接続** 推奨。

#### Mac

```
1. システム設定 を開く
2. 「Apple Intelligence & Siri」をクリック
3. 同様の手順
```

### 言語設定（重要）

Apple Intelligence の **言語と地域設定** を確認：

```
設定 → 一般 → 言語と地域
   ↓
「優先する言語」が日本語であることを確認
   ↓
iOS 18.4 以降なら日本語版 Apple Intelligence が動作
```

## Step 2：Writing Tools の使い方（10分）

### 基本操作

#### 文章を選択して機能を呼び出す

```
1. メール・メモ・メッセージ等で文章を入力
2. 文章を「長押し」して「テキストを選択」
3. メニューから「Writing Tools」を選択
4. 5つの機能から選択
```

#### Writing Tools の5つの機能

| 機能 | 用途 |
|---|---|
| **書き直す** | リライト（複数バリエーション提示） |
| **プロフェッショナル** | ビジネスフォーマルにリライト |
| **カジュアル** | 友達向けにフレンドリーに |
| **校正** | 誤字脱字・文法チェック |
| **要約** | 長文を箇条書きにまとめ |

### 実用例1：メール返信

#### Before（自分が書いた草稿）
```
来週の打合せ、ちょっと厳しいです。
別の日にできませんか。
```

#### Writing Tools「プロフェッショナル」適用
```
お世話になっております。
誠に恐れ入りますが、来週の打合せにつきまして
日程の調整が難しい状況です。
別日への変更をお願いできますでしょうか。
ご検討のほどよろしくお願いいたします。
```

→ **3秒で**ビジネスフォーマルに変換。

### 実用例2：長文要約

#### Before（10,000字の業界レポート）
全文を選択 → Writing Tools → 「要約」

#### After（300字の要約）
```
本レポートは2026年Q1のAI業界の主要動向を整理：
1. ChatGPT Agent Mode 2.0 のリリース
2. Claude Design β 公開
3. Apple Intelligence 日本語対応
...
（続く）
```

→ **5秒で**主要ポイントだけ抽出。

### 実用例3：チャット返信

iMessage や LINE で：

```
相手「明日の懇親会、来る？」

自分が「行きたいけど予定が...」と曖昧に返したい
       ↓
Writing Tools → 「カジュアル」
       ↓
「行きたいんだけどさ、ちょっと予定詰まってて、
 後でまた連絡するね！」
```

→ **自然な口調**に整形。

### 実用例4：プレゼン資料の整形

Pages や Word で：

```
入力した箇条書きメモ
       ↓
全選択 → Writing Tools → 「表形式に変換」
       ↓
データが整然とした表に
```

→ **資料作成時間が60%削減**。

## Step 3：Siri 強化機能（15分）

### 連続コマンドの使い方

#### Before（従来の Siri）
```
「Hey Siri、明日の天気は？」
→ 回答
「Hey Siri、雨なら傘リマインダーを」
→ 回答
「Hey Siri、家族にも天気を共有」
→ 回答

3往復必要
```

#### After（Apple Intelligence Siri）
```
「Hey Siri、明日の天気を教えて。
 もし雨なら傘持っていくリマインダーをセットして、
 家族にも雨予報を共有して」

→ 1往復で全部処理
```

### 画面コンテキスト機能

Siri が**今見ている画面**を理解：

```
1. メールアプリで取引先のメールを開く
2. 「Hey Siri、これを翻訳して」
3. → 開いているメール本文を自動的に翻訳
```

→ **コピペ不要**で AI 操作。

### タイピング Siri

声を出せない場面（電車・会議中）で：

```
1. iPhone：サイドボタンを長押し
2. キーボード表示
3. テキストで Siri に質問
```

### よく使う Siri コマンド10選

```
1. 「明日の天気と通勤情報を教えて」
2. 「来週の月曜の14時から1時間、〇〇さんとのミーティングを設定」
3. 「今のLINEを家族に転送」
4. 「直近の写真3枚を母に送って」
5. 「今のSafariのページを後で読むに保存」
6. 「夜10時に〇〇のリマインダーをセット」
7. 「今のメモを翻訳して英語にして」
8. 「直近のメールから〇〇の件をまとめて」
9. 「明日の予定を読み上げて」
10. 「これは ChatGPT で答えて」（複雑な質問用）
```

## ChatGPT 連携の設定

### 連携手順

```
1. 設定 → Apple Intelligence & Siri
2. 「拡張機能」をタップ
3. 「ChatGPT」を ON
4. （オプション）OpenAI アカウントでログイン
   - Free アカウント：無料で利用
   - Plus アカウント：Plus 機能も利用可
```

### 連携後の使い方

```
複雑な質問を Siri に投げる：

「Hey Siri、AI業界における2026年Q2の重要トピックを5つ
教えて、それぞれの背景と影響も含めて」

→ Siri：「これは ChatGPT で答えますか？」
→ Yes
→ ChatGPT 4o が詳細回答
```

### 注意点

- **ChatGPT に送信される情報**は確認画面に表示
- 機密情報の質問は **拒否（No）** を選択
- OpenAI のプライバシーポリシーが適用される

## Image Playground の使い方

### 起動方法

```
1. 設定済みのアプリ：Messages・Pages・Notes・Freeform 等
2. アプリ内から「Image Playground」アイコンをタップ
3. プロンプトを入力（英語推奨）
4. スタイル選択：アニメ / イラスト / スケッチ
5. 生成
```

### 制限事項

- **フォトリアル画像は意図的に除外**（フェイク防止）
- **既存ブランド・著名人**は生成しない
- **大量生成は商用利用上限**あり

## Genmoji の使い方

### 作成手順

```
1. キーボードで絵文字パレットを開く
2. 上部の「Genmoji を作成」をタップ
3. 説明テキスト入力（例：「夜遅くまで働く猫」）
4. AI が複数案生成
5. 気に入ったものを選択 → 送信
```

### 注意点

- **受信側が iOS 18.1 以降**でないと表示されない
- 既存の絵文字とは別物として扱われる
- 対面で説明したいなら通常絵文字推奨

## トラブル対処

### トラブル1：「Apple Intelligence を有効にする」が表示されない

#### 原因
- 対応端末でない（iPhone 15 Pro 未満等）
- iOS バージョンが古い
- 地域設定が日本以外

#### 対処
- 設定 → 一般 → ソフトウェアアップデート で最新版へ
- 言語と地域が日本になっているか確認

### トラブル2：ダウンロードが進まない

#### 原因
- Wi-Fi が不安定
- 端末容量不足

#### 対処
- 高速 Wi-Fi に接続
- ストレージを5GB以上空ける
- 再起動して再試行

### トラブル3：Writing Tools が表示されない

#### 原因
- 文字を選択していない
- アプリが対応していない（一部の古いアプリ）

#### 対処
- 文字を「長押し」してから選択
- 別のアプリで試す

### トラブル4：Siri が反応しない

#### 原因
- 「Hey Siri」設定が無効
- マイクが汚れている
- 周囲のノイズが大きい

#### 対処
- 設定 → Siri → 「Hey Siri」を再学習
- マイク部分を清掃
- 静かな場所で試す

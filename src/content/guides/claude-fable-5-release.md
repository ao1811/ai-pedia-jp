「Claude に Opus より上のモデルが出たらしい」「Mythos って結局なに？」——2026年6月9日の Anthropic の発表以降、AI 界隈で一気に話題になったのが **Claude Fable 5** です。本記事では、Anthropic の公式発表と各社報道をもとに、Fable 5 とは何か・料金・使えるプラン・安全機構を、事実ベースで整理します。

> 本記事の事実情報は、Anthropic 公式発表（2026年6月9日、「Claude Fable 5 and Claude Mythos 5」）および主要メディアの報道に基づきます。編集部の解釈・おすすめは「編集部見解」と明記しています。

## 結論：3行でわかる Claude Fable 5

- **正体**：これまで一部組織にしか提供されてこなかった「Mythos 級」性能を、安全機構付きで**一般公開した版**
- **位置づけ**：Opus の**上位ティア**（新しい区分）。Anthropic は「一般提供してきたどのモデルも上回る」と説明
- **使う前の注意**：料金は Opus 4.8 の倍（$10/$50）。Pro/Max/Team の**無料枠は6月22日まで**で、6月23日以降は別途クレジットが必要

## Fable 5 と Mythos：名前の整理

ニュースで「Mythos」「Fable」「Fable 5」と複数の名前が飛び交って混乱しやすいので、まず整理します。

| 名前 | 何か | 誰が使える |
|---|---|---|
| **Mythos（旧）** | 高性能ゆえに一般公開を見送り、一部組織に限定提供されていたモデル群 | 限定パートナーのみ |
| **Fable 5** | Mythos 級の性能を**安全機構付きで一般公開**した版 | API は誰でも／Pro・Max・Team も（期間条件あり） |
| **Mythos 5** | 一部領域で安全機構を解除した版 | Project Glasswing パートナー・一部の生物医学研究者に限定 |

Anthropic の説明では、**Fable 5 と Mythos 5 は同じ土台のモデル**で、違いは「安全分類器が働くかどうか」です。つまり一般ユーザーが手にする Fable 5 は、「中身は Mythos 5 と同じだが、危険な使い方には蓋をしてある版」という理解が近いです。

## 料金：Opus 4.8 の倍

API 料金は、Fable 5・Mythos 5 ともに以下のとおりです（公式発表）。

| モデル | 入力（100万トークン） | 出力（100万トークン） |
|---|---|---|
| **Claude Fable 5** | **$10** | **$50** |
| Claude Opus 4.8 | $5 | $25 |
| Claude Sonnet 4.6 | $3 | $15 |

Anthropic は、この $10/$50 という価格を「Mythos Preview の半額以下」と表現しています。とはいえ、現行フラッグシップの Opus 4.8 と比べると入出力ともに**ちょうど2倍**です。

> **編集部見解**：価格が2倍ということは、同じ作業をさせると単純にコストも2倍に近づきます。「とりあえず一番賢いモデル」で全部回すと請求が跳ねやすいので、**常用は Opus 4.8、要所だけ Fable 5** という使い分けが現実的です。具体的な線引きは[Fable 5 と Opus 4.8 の使い分け](/guides/claude-fable-5-vs-opus-4-8/)で解説します。

## 使えるプランと「6月23日」の注意点

ここが一番見落とされやすいポイントです。

- **API**：誰でも利用可能（従量課金）
- **Claude Pro / Max / Team / 席課金型 Enterprise**：
  - **2026年6月9〜22日**：追加料金なしで利用可能
  - **2026年6月23日以降**：別途の利用クレジット購入が必要
  - 容量が整えば標準機能として戻す方針（時期は未公表）

つまり、**サブスクで無料のうちに試せるのは6月22日まで**。それ以降に Pro などで Fable 5 を使い続けるには、追加のクレジットがいる形になります。

> **編集部見解**：「無料枠のあるうちに、自分の実務で Opus 4.8 との差が体感できるか試す」のがおすすめです。差を感じなければ6月23日以降に無理して課金する必要はありません。

## 何がすごいのか：公式が挙げた具体例

抽象的な「最高水準」だけだとピンと来ないので、Anthropic が発表で挙げた具体例を紹介します（いずれも公式発表・報道ベース）。

- **大規模コード移行**：Stripe の事例として、約5,000万行規模の Ruby コードベースの全体移行を、チームで手作業なら2か月以上かかる規模のところを短期間でこなしたと報告
- **視覚だけでゲーム攻略**：補助ツールなしで、画面の視覚情報だけを頼りにポケモン（FireRed）をプレイ
- **コーディング評価**：Cognition の FrontierCode 評価で、中程度の effort 設定でも最高スコア
- **科学領域**：ウイルスの殻（shell）構造の組み立て予測で、その分野専用に作られたモデルを上回る結果

ソフトウェア開発・知識労働・画像認識・科学研究といった幅広い領域で、これまでの一般提供モデルを超える性能が示された、というのが発表の骨子です。

## 安全機構：高リスクの話題は Opus 4.8 が答える

Fable 5 の大きな特徴が、**安全フォールバック**です。

- **対象**：サイバーセキュリティ、生物・化学、蒸留（distillation）など高リスクと判定される話題
- **挙動**：その場合、Fable 5 ではなく **Claude Opus 4.8 が応答**する
- **頻度**：Anthropic によれば、フォールバックが起きるのは**平均で全セッションの5%未満**（95%超は通常どおり Fable 5）

背景として、Anthropic はこのモデル系統について「AI が危険になりつつある」という趣旨の警告を出した直後に一般公開した、という経緯が報じられています。強力さゆえに、安全側に倒した設計になっているわけです。

> **編集部見解**：一般的な業務・学習・コーディング用途であれば、フォールバックを意識する場面はまずありません。「危ない使い方をしようとすると、自動的に1段おとなしいモデルに切り替わる」程度の理解で十分です。

## API で使うときの注意点

開発者向けに、API の要点だけ補足します。

- **モデル ID**：`claude-fable-5`
- **思考（thinking）**：adaptive のみ。`budget_tokens` や `temperature` / `top_p` / `top_k` は使えません（送るとエラー）
- **Fable 5 固有の注意**：思考を明示的に「disabled」にすると 400 エラーになります。思考を使いたくない場合は `thinking` パラメータ自体を省略してください
- **effort**：`low`〜`max` に加え `xhigh` も利用可能。コーディング・エージェント用途は `high`〜`xhigh` が目安

API の細かい仕様は更新される可能性があるため、本番実装前に [Anthropic 公式ドキュメント](https://platform.claude.com/docs/en/about-claude/models/overview) で最新を確認してください。

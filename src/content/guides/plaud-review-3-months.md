## 期待外れだった点 TOP 3

### ① 日本語固有名詞・専門用語の精度

#### 具体例
```
正解：「インシデント管理」
誤認識：「インスタント管理」

正解：「リテンション」
誤認識：「リテンション ション」（重複）

正解：「PdM（プロダクトマネージャー）」
誤認識：「P で M」
```

業界用語・社内用語は**手修正**が必要。

#### 対策
- PLAUD アプリの「**カスタム辞書**」機能で社内用語を登録
- ただし**辞書反映は次回録音から**なので、過去録音には効かない

### ② 方言・なまりの認識

関西弁・東北弁・九州弁などが混ざると精度低下：

```
関西弁：「そやな〜、ほんまそうやな」
誤認識：「そやな〜、本間そうやな」（人名と誤認）

東北なまり：「したらば〜」
誤認識：「したらば」が認識されないことが多い
```

**標準語前提**で設計されているのが分かる。

### ③ ノイズの多い環境での精度低下

カフェ・空港・電車内での録音は：

- 周囲の話し声と区別できない
- 音楽・BGM が混ざると精度大幅低下
- 屋外の風切り音で聞き取れない箇所増加

**静かな場所での録音前提**のツール。
